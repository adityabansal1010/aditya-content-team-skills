# LinkedIn Post Writer

Write fully drafted, ready-to-publish LinkedIn posts using proven short-form post formats — adapted
to the specific person's (or client's) niche, audience, and voice. The full library of 50 formats
lives in `references/post-formats.md`; load it when you're ready to draft.

## Step 0: Whose post is this for?

Ask up front: is this post for the ghostwriter's own LinkedIn presence, or for a client's?

- **Own voice**: write in the user's natural voice and draw on their real experiences/opinions.
- **Client's voice**: ask for (or confirm) what the user knows about the client's voice, tone,
  experiences, and opinions — the post needs to sound like the client, not like a generic
  professional. If the user has run the Audience Research or Content Pillars skills in this plugin
  for this client already, use that context too.

## Step 1: Gather what you need

Collect, if not already provided:

| Field | Notes |
|---|---|
| **Topic / idea** | What's this post about? (Could come straight out of the Content Pillars skill's idea bank) |
| **Target audience** | Who should this post resonate with? |
| **Voice** | Whose voice — the user's or a client's — and any notes on tone/style |
| **Specific stories, achievements, data, or opinions** | Optional, but makes the post feel real and specific rather than generic |

If the user only gives a topic, ask for audience and voice before drafting — a post written without
knowing who it's for or whose mouth it's coming out of will read generic.

## Step 2: Load the format library and draft

Read `references/post-formats.md` for the full set of 50 proven short-form post format skeletons
(Universal Feelings, Hacks, Contrarian Views, Amateurs vs Pros, Biggest Mistakes, and so on).

Pick the 5 formats from that library that best fit the topic, audience, and voice — don't force a
format that doesn't naturally suit the idea. Write 5 complete, ready-to-publish LinkedIn posts:

- Fill every bracketed placeholder with real, specific content — never leave template brackets in
  the output.
- Write in the confirmed voice (the user's own, or the client's, as established in Step 0).
- Keep posts scannable and punchy: short paragraphs, liberal line breaks, mobile-friendly formatting,
  professional-but-personal LinkedIn tone (not the punchier/more casual tone that might suit X).
- Ground each post in real specifics — actual numbers, stories, opinions, or language from the
  user/client — rather than generic statements that could apply to anyone.

Present each post with the format name in bold, the fully written post beneath it, and a blank line
between posts.

## Step 3: Offer more

After presenting the 5 posts, ask: **"Want me to generate 5 more using different formats, want to
revise the voice/angle on any of these, or want to lock one in and move on?"**

If the user wants more, pick 5 *different* formats than the previous batch.

## Reminders

- Every post must be fully written and ready to publish — not a fill-in-the-blank template.
- If this came out of the Content Pillars skill's idea bank, lean on that context (pillar, audience
  archetype, content bucket, sub-topic) to sharpen the angle and keep it consistent with the
  broader content strategy.
- Keep all output in chat. Only save posts to a document if the user explicitly asks.
