# LinkedIn Content Pillars & Multiplication

Guide the user step-by-step through the Lean Content Multiplication Method to build a systematic
content idea bank. This is an **interactive, sequential process** — confirm each building block
with the user before moving to the next step. Don't generate the final content ideas until all
the building blocks (pillar, audience, sub-topic, bucket) are confirmed.

## Step 0: Whose content strategy is this for?

Ask up front: is this for the ghostwriter's own content, or for a client's content?

Either way, gather the same starting context: their niche, areas of expertise, target audience, and
content goals. If this is for a client and the user doesn't have all of this yet, note that the
Audience Research skill in this plugin is a good source for audience-side detail, and the
Positioning Consultant skill for niche/expertise framing.

## The 5 variables (your reference frame throughout)

Keep these definitions in mind as you guide the process — they're what make the system work:

1. **Content Pillars** — the 3-5 core expertise areas that form the content foundation. Each must
   be broad enough to explore for months, focused enough that the audience instantly sees its
   relevance, and aligned with real expertise/experience. Avoid pillars that are too generic
   ("business") or too narrow ("Instagram carousel design for dentists").
   Example set (Real Estate Investing): Property Acquisition, Financing Strategies, Property Management.
2. **Content Buckets** — the 3 universal content types: **Futurism** (where the industry is
   headed), **Your Story** (lessons from personal experience), **Actionable Advice** (specific,
   practical guidance). Each serves a different psychological need — expertise/forward-thinking,
   trust/vulnerability, immediate value/competence.
3. **Magical Multipliers** — the 10 angles that turn one topic into 10 distinct pieces: Tips,
   Stats, Steps, Lessons, Benefits, Reasons, Mistakes, Examples, Questions, Personal Stories. Each
   must produce genuinely different content, not reworded duplicates.
4. **Audience Archetypes** — 3-5 segments within the broader audience (by experience level, role,
   industry/vertical, life stage, or business size) that need the same core message tailored to
   their specific situation and language.
5. **Sub-Topic Expansion** — variations on a core topic by changing tools/platforms, time frames,
   budget levels, experience levels, industry applications, or scale (individual/team/company-wide).

## The guided process — follow these steps in order

**Step 1 — Content Pillars.** Generate 3 candidate Content Pillars based on the niche/expertise the
user shared. Present them and ask the user to review, modify, or approve before continuing.

**Step 2 — Audience Archetypes.** Generate 3-5 candidate audience archetype segments. Present them
and ask the user to confirm or modify before continuing.

**Step 3 — Sub-Topics.** Generate suggested sub-topics (variations on core themes within the
confirmed pillars). Present them and ask the user to confirm or modify before continuing.

**Step 4 — Select a pillar.** Ask the user to choose ONE confirmed pillar to focus the
multiplication process on.

**Step 5 — Select an audience.** Ask the user to choose ONE confirmed audience archetype to focus on.

**Step 6 — Select a sub-topic.** Ask the user to choose ONE confirmed sub-topic to focus on.

**Step 7 — Select a content bucket.** Ask the user to choose ONE content bucket (Futurism, Your
Story, or Actionable Advice) to focus on.

**Step 8 — Generate the multiplication.** Produce 10 Magical Multiplier ideas — running the chosen
pillar × chosen content bucket × the 10 multiplier angles (Tips, Stats, Steps, Lessons, Benefits,
Reasons, Mistakes, Examples, Questions, Personal Stories) × the chosen sub-topic — tailored to the
chosen audience archetype. Use this exact output format:

```
[Sub-Topic] for [Audience Archetype]
[Content Bucket] for [Pillar]
- Idea #1 (Tips angle): ...
- Idea #2 (Stats angle): ...
- Idea #3 (Steps angle): ...
- Idea #4 (Lessons angle): ...
- Idea #5 (Benefits angle): ...
- Idea #6 (Reasons angle): ...
- Idea #7 (Mistakes angle): ...
- Idea #8 (Examples angle): ...
- Idea #9 (Questions angle): ...
- Idea #10 (Personal Stories angle): ...
```

Each idea must be a genuinely distinct, specific, postable content idea — not a reworded version of
another idea on the list. Ground every idea in the actual niche and audience, never generic
business advice.

**Step 9 — Offer to repeat.** Ask if the user wants to repeat the process for a different pillar.

**Step 10 — Loop.** If they say yes, jump back to Step 4 (re-selecting pillar/audience/sub-
topic/bucket from the already-confirmed building blocks — no need to regenerate pillars, archetypes,
or sub-topics unless the user wants to revisit those too).

## Reminders

- Never skip ahead or batch multiple steps together — this only works if each building block is
  confirmed before the next is built on top of it.
- Keep ideas specific to the niche and grounded in real expertise — generic "10 tips for success"
  style ideas defeat the purpose of the system.
- This skill pairs naturally with the Post Writer skill in this plugin — once an idea is chosen
  from the bank, point the user there to actually draft the post.
- Keep all output in chat unless the user asks to save the idea bank as a document or spreadsheet.
